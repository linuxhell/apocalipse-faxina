# Apocalipse Faxina

Aplicativo portátil de limpeza, manutenção e reparo para **Windows x64**, escrito em Rust.

Primeira versão: **Português do Brasil**.

## Objetivos do projeto

- análise antes da limpeza com espaço recuperável;
- regras próprias + suporte a Winapp2.ini;
- limpeza de temporários, caches e resíduos;
- manutenção de drivers no fluxo normal → forçado quando necessário;
- Registro com abordagem conservadora e backup;
- inicialização, tarefas agendadas, serviços e menu de contexto;
- SFC/DISM e reparo de Internet;
- exclusões;
- 20 temas claros/escuros e controle de transparência;
- interface portátil organizada.

> As ações destrutivas devem ser revisadas antes da execução. O projeto prioriza segurança e reversibilidade.
